# whitelist

Passage smart contract crate for whitelist.

## Overview

This contract is part of the Passage CosmWasm workspace.

## Build

```bash
cargo build --package whitelist --release
```

## Generate Schema

```bash
cargo run --package whitelist --example schema
```

## Test

```bash
cargo test --package whitelist
```

- Source code: src/
