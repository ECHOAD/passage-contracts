# pg721-metadata-onchain

Passage NFT collection contract with the metadata stored onchain

## Overview

This contract is part of the Passage CosmWasm workspace.

## Build

```bash
cargo build --package pg721-metadata-onchain --release
```

## Generate Schema

```bash
cargo run --package pg721-metadata-onchain --example schema
```

## Test

```bash
cargo test --package pg721-metadata-onchain
```

## Notes

- Source code: src/
- Generated JSON schemas: schema/
