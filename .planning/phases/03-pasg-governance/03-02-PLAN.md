# Phase 03-02 - Weighted Voting, Delegation, and Threshold Rules

## Objective

Add PASG-weighted voting, delegation, quorum, and approval enforcement on top of the lifecycle introduced in 03-01, using deterministic proposal snapshots and contract-visible delegation state.

  </acceptance_criteria>
  <done>Governance outcome math is based on snapshot PASG power rather than mutable member counts.</done>
