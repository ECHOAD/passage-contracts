# Phase 03-01 - Governance Lifecycle and Scoped Action Surface

## Objective

Replace fixed-member-only proposal flow with a PASG-holder governance lifecycle that still uses the existing `multisig` contract family, while narrowing proposal execution to protocol-governable actions instead of arbitrary admin behavior.
