# pg721

## Estado

Actual

## Proposito

Define el contrato principal de coleccion tipada de Passage usado para creator assets y semanticas duraderas on-chain.

## Instanciacion

Se instancia con datos de ownership/admin de la coleccion, metadata de tipo NFT, comportamiento de royalties y las reglas de coleccion que impone el modelo base.

Fuente real de payload: `contracts/nft/pg721/src/msg.rs` y `schema/` cuando exista.

## Actores y permisos

Owner/admin de la coleccion, minters, marketplaces, registry y holders de tokens.

## Mensajes clave

- Almacena metadata tipada a nivel de coleccion y reglas de ownership.
- Soporta minting, transfer, approval y comportamiento de coleccion aware de royalties.
- Actua como la superficie central de coleccion sobre la que trabajan minters y marketplaces.
- Mantiene `token_uri` como el puntero al manifiesto para render, detalle runtime y compatibilidad expandida.
- Mantiene `profile_id` como marcador minimo de compatibilidad de Passage cuando importa la interoperabilidad de avatar o companion.
- No trata progresion mutable ni estado de instalacion como metadata NFT generica.

## Relaciones

- Suele desplegarse via `collection-factory` o `minter-v2`.
- Entrega identidad de coleccion y nft_type a registry.
- Se ubica debajo de los flujos de marketplace, auction, whitelist y royalty-group.
- Se compone con superficies dedicadas como `avatar-progression` y `world-plugin-assignment` cuando el protocolo necesita guardar estado mutable on-chain.

## Ejemplo hipotetico

Flujo hipotetico: una coleccion de avatares usa `pg721` para ownership, approvals e identidad tipada, mientras el manifiesto detras de `token_uri` carga payloads visuales y los modulos de estado guardan hechos mutables confiables.
