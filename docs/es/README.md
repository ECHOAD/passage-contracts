# Documentacion de Contratos de Passage

Este arbol contiene la documentacion bilingue en espanol para todos los contratos del workspace.

## Orden recomendado

1. `overview.md`
2. `relationships.md`
3. `instantiate-guides.md`
4. `flows.md`
5. `contracts/core/*.md`
6. `contracts/nft/*.md`
7. `contracts/relationship/*.md`
8. `contracts/staking/*.md`
9. `contracts/legacy/*.md`

## Familias

- `contracts/core`: registro, factories, ruteo, billing, admin y governance
- `contracts/nft`: colecciones, minters, marketplace, auctions, royalties y listas de acceso
- `contracts/relationship`: primitivas sociales
- `contracts/staking`: staking de NFT y rewards asociados
- `contracts/legacy`: superficies historicas o de compatibilidad

## Nota importante

Esta documentacion explica el comportamiento actual del repositorio. No agrega nuevas capacidades y no sustituye `msg.rs`, `schema/` o el codigo fuente como fuente final de verdad.
