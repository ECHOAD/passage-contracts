# Passage Contract Documentation

This tree contains the mirrored English documentation for every contract in the workspace.

## Recommended reading order

1. `overview.md`
2. `relationships.md`
3. `instantiate-guides.md`
4. `flows.md`
5. `contracts/core/*.md`
6. `contracts/nft/*.md`
7. `contracts/relationship/*.md`
8. `contracts/staking/*.md`
9. `contracts/legacy/*.md`

## Families

- `contracts/core`: registry, factories, routing, billing, admin, and governance
- `contracts/nft`: collections, minters, marketplace, auctions, royalties, and allowlists
- `contracts/relationship`: social graph primitives
- `contracts/staking`: NFT staking and related reward modules
- `contracts/legacy`: historical or compatibility surfaces

## Important note

These docs explain current repo behavior. They do not add new capabilities and they do not replace `msg.rs`, `schema/`, or the source code as the final source of truth.
