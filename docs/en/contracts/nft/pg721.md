# pg721

## Status

Current

## Purpose

Defines the main typed Passage collection contract used for creator assets and collection-level metadata.

## Instantiation

Instantiate with collection ownership/admin data, NFT-type metadata, royalty behavior, and any collection-level parameters enforced by the base collection model.

Real payload source of truth: `contracts/nft/pg721/src/msg.rs` and `schema/` when available.

## Actors and permissions

Collection owner/admin, minters, marketplaces, registry, and token holders.

## Key messages

- Stores collection-level typed metadata and ownership rules.
- Supports minting, transfer, approval, and royalty-aware collection behavior.
- Acts as the core collection surface that minters and marketplaces build around.

## Relationships

- Is commonly deployed through `collection-factory` or `minter-v2`.
- Feeds collection identity and NFT type into registry.
- Sits underneath marketplace, auction, whitelist, and royalty-group flows.

## Hypothetical example

Hypothetical flow: a world-template collection uses `pg721` as its contract base, then registry and commerce contracts reason over that collection as the canonical NFT surface.
